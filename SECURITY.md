# Security

Report a vulnerability in this SDK or in the AY Inbox API to team@ayinbox.com. Please do not open a public issue for it.

Include what you found, how to reproduce it, and the SDK version. We will acknowledge the report and keep you updated while we fix it.

Never paste a real API key (`aybox_...`), OAuth token (`ayat_...`) or webhook secret (`whsec_...`) into an issue, a log or a report. If one was exposed, revoke it in the dashboard at https://app.ayinbox.com.
